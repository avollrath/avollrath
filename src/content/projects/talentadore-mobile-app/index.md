A **recruitment SaaS mobile app** has to be selective. TalentAdore's desktop product covered applicant tracking, candidate pipelines, messaging, job management, analytics, and recruiter workflows, but putting all of that onto a phone would have produced a cramped copy of the desktop UI.

This project was a mobile concept and prototype in Adobe XD. The external design-selection archive references TalentAdore interface work, including applicant views and event/marketing design, which gives useful context: the mobile app concept came from a real product environment rather than an isolated redesign exercise. The goal was to identify which parts of an ATS actually make sense on mobile, then turn those into a compact flow.

The design work focused on recruiter tasks that benefit from quick access: reviewing candidate status, checking pipeline movement, reading messages, and taking lightweight action without needing the full desktop workspace. The interesting constraint was density. Recruitment software carries a lot of state, so the mobile interface needed to reduce information without hiding the decisions a recruiter needs to make. The result is best understood as product design exploration: not a production frontend, but a realistic UX prototype for mobile recruiting workflows.
