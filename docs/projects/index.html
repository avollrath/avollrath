Wolt Ratings - Order History Tracker

Wolt Ratings exists because Wolt gives you no way to remember which venues were worth reordering from or which dishes disappointed you — your order history is just a receipt archive with no memory.

It's a Chrome extension that captures your session token and syncs your full order history to a local Flask backend, paired with a dashboard where you can search, filter, rate orders with stars, and attach personal notes. Clicking a venue opens a modal with per-restaurant stats, your most ordered items, and a full visit history.

Everything stays local — no accounts, no cloud, no tracking. Orders are stored in a plain JSON file you can import and export freely.

Check it out: Wolt Ratings on GitHub

FlipSite - Inventory and Resale Tracker

FlipSite is a personal inventory and resale tracker I built to replace a spreadsheet that was getting hard to maintain.

It tracks what I own, what I paid, and where I bought it — with photos, receipts, and files attached per item so everything related to a purchase stays in one place. When I sell something, it calculates the actual profit, including across bundles where one purchase splits into multiple items sold separately.

The backend runs on Supabase for auth, file storage, and per-user data isolation. The frontend uses React and TanStack Query for data fetching, with a table view, photo gallery, dashboard analytics, and eight color themes with light and dark mode.

HyperType

HyperType is a neon arcade typing game I built to make practicing touch typing actually enjoyable.

I wanted something that feels fast, responsive, and satisfying, where every correct keypress has clear visual and audio feedback. The game turns typing into a simple combat loop, words come in, you type them, and they disappear in a burst of light and sound.

Along the way I explored game feel, timing and feedback, and how small details like sound effects, particles, and UI responsiveness can make a big difference.

The game includes multiple difficulty modes, achievements, and score tracking to make it something you can come back to and gradually improve at.

Marathon Control Center

Marathon Control Center is a focused dashboard I built when my first full marathon was suddenly only three weeks away.

After a long break from consistent running — travel, winter, sickness, holidays, and life in general — I needed something more concrete than a training note or spreadsheet.

The app turns the last weeks into a clear system with runs, gym sessions, shoe testing, and actual kilometre tracking in one place.

It works like a compact habit tracker for a high-stakes training block, with persistent progress, backup/export, and optional Supabase sync.

The interface follows a dark, geometric, industrial design language with neon accent states, built with React, TypeScript, and Tailwind CSS.

CTC - Chess.com Trading Card

CTC - Chess.com Trading Card turns a Chess.com player profile into a collectible fantasy card.

The app fetches public player data from the Chess.com API, derives gameplay attributes like rarity, tactics, speed, and prestige, and generates a themed card identity including name, lore, and artwork.

The result is presented as an animated card with 3D tilt, shine effects, and download/share functionality. AI generation is used for card text and artwork, with deterministic fallbacks to ensure the card always renders cleanly.

PasiLunch

PasiLunch is a small web service and Slack integration that collects daily lunch menus from restaurants in Pasila, Helsinki.

Instead of checking multiple restaurant websites every day, it brings everything together in one place through a simple web interface and a Slack command.

Built with Node.js, Express, and Cheerio, the project scrapes menu data and uses the Gemini API to normalize different menu formats into one consistent structure.

Menus are cached and processed once per day to keep the data fresh while minimizing scraping and API usage. The Slack integration adds a bit of personality with randomized humorous messages.

Vollrath Drum Machine

Vollrath Drum Machine is a browser-based step sequencer inspired by classic hardware drum machines.

The interface features a 16-step sequencer, five instrument channels, per-channel volume controls, playback speed settings, and preset patterns.

Built with pure JavaScript and CSS, the project explores sequencing logic, timing control, and browser-based audio playback without relying on frameworks.

Patterns can be saved with localStorage, while GSAP animations and custom CSS styling give the interface a tactile, hardware-inspired feel.
